headercheck

Grade any site's HTTP security headers in seconds, with the exact fix for every gap.

$ python3 headercheck.py https://example.com

https://example.com  ->  HTTP 200  grade D (34%)
  [F] strict-transport-security   MISSING
       HSTS: forces HTTPS. Add 'max-age=63072000; includeSubDomains; preload'.
  [leak] server: ECS (nyb/1D18)  (consider removing)

Eight checks, one grade

HSTS, CSP, nosniff, frame options, referrer and permissions policies, COOP/CORP - scored A+ to F.

Fix advice included

Every missing header comes with the value to set, not just a red X.

Posture over time

JSON output and CI-friendly exit codes track your grade release over release.

$ python3 headercheck.py https://app.example.com -o posture.json
